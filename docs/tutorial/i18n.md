# Alarm I18n

<!-- Diátaxis type: Tutorial -->

In this tutorial, we will look up alarm messages in multiple languages, format
them for display, and enrich raw alarm payloads with localized metadata. By the
end you will know how to use `AlarmI18n` and the `language` parameter on
`DobotRobot`.

## Prerequisites

- The `dobot_api_v3` package is [installed](../getting-started/installation.md).

## Step 1 — Create an `AlarmI18n` instance

The `AlarmI18n` class loads alarm definitions from the bundled YAML locale files
(`alarms.en.yml`, `alarms.zh_CN.yml`):

```python
from dobot_api_v3 import AlarmI18n

i18n = AlarmI18n(default_language="en")
print("Supported languages:", i18n.get_supported_languages())
```

**Expected output:**

> ```
> Supported languages: ['en', 'zh_CN']
> ```

## Step 2 — Look up individual alarms

We can query controller and servo alarms by their numeric ID:

```python
controller_alarm = i18n.get_controller_alarm(16)
servo_alarm = i18n.get_servo_alarm(8000)
print("Controller alarm:", controller_alarm)
print("Servo alarm:", servo_alarm)
```

**Expected output:**

> ```
> Controller alarm: {'id': 16, 'description': '...', 'cause': '...', 'solution': '...'}
> Servo alarm: {'id': 8000, 'description': '...', ...}
> ```

## Step 3 — Format alarms for display

The `format_alarm()` method returns a human-readable string:

```python
print(i18n.format_alarm(16, alarm_type="controller"))
```

**Expected output:**

> ```
> [Controller Alarm 16] <description> | Cause: <cause> | Solution: <solution>
> ```

## Step 4 — Switch language

We can switch to Chinese at runtime:

```python
i18n.set_language("zh_CN")
print(i18n.format_alarm(16, alarm_type="controller"))
```

**Expected output:**

> The same alarm, now with Chinese description, cause, and solution fields.

## Step 5 — Enrich raw alarm data

Given a minimal alarm dict, `enrich_alarm_data()` merges in the localized
fields:

```python
enriched = i18n.enrich_alarm_data({"id": 16, "type": "controller"})
print("Enriched:", enriched)
```

**Expected output:**

> ```
> Enriched: {'id': 16, 'type': 'controller', 'description': '...', 'cause': '...', 'solution': '...'}
> ```

## Step 6 — Use i18n with `DobotRobot`

The `DobotRobot` constructor accepts a `language` parameter that is forwarded
to the built-in `RobotErrorMonitor`:

```python
from dobot_api_v3 import DobotRobot

with DobotRobot("192.168.5.1", language="zh_CN") as robot:
    robot.check_errors()   # alarm messages logged in Chinese
```
